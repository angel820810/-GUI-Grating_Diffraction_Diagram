GRATING DIFFRACTION DIAGRAM GENERATOR
Developed by Yen-Chi Chung (Angel)

I developed this GUI to make grating diffraction easier to visualize.
It converts refractive indices, incident angle, wavelength, and grating
pitch into a diagram of allowed reflected and transmitted orders.

The tool supports quick exploration of how design parameters change
propagation directions, without repeatedly editing calculation scripts.
It evaluates diffraction angles, not diffraction efficiency.

See the accompanying PPT for the equations, examples, and user guide.
